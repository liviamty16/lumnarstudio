LUMNAR STUDIO — PORTFÓLIO
=========================

Arquivo principal:
- index.html

Assets:
- assets/lumnar-mark.svg

O portfólio utiliza previews AO VIVO das seis landing pages hospedadas na Vercel:
1. Creative Studio
2. Vértice Travel
3. Atelier dos Amigos
4. Nova Solar
5. PulsePods
6. Lumnar Digital

IMPORTANTE
---------
Os previews dentro dos cards são iframes que dependem de internet.
Mesmo se um navegador bloquear o preview, o botão "Visitar projeto ao vivo"
continua apontando para a URL real de cada LP.

Publicação:
- Pode subir diretamente para Vercel, Netlify ou GitHub Pages.
- O index.html deve ficar na raiz.
- A pasta assets deve ficar ao lado do index.html.

Direção criada para o portfólio:
- identidade própria Lumnar Studio
- logo abstrata baseada em L + luz/lua
- dark editorial / premium
- foco em apresentação para empresas e oportunidades internacionais
- previews ao vivo das LPs
- responsivo
- animações sutis
- sem dependência de frameworks

Contato:
O CTA final foi escrito sem inventar e-mail/WhatsApp.
Se quiser, substitua o texto do bloco #contato pelo seu e-mail,
LinkedIn ou WhatsApp real antes de publicar.
