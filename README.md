# ALANA MYSTERY — v1.0

Primeira versão do protótipo interativo, refeita para ter uma abertura mais cinematográfica e **mobile-first**, especialmente confortável no iPhone.

## O que existe nesta versão

- Boot curto e elegante, sem telas longas.
- Entrada por toque em um “sinal”.
- Micro-revelação narrativa.
- Primeiro puzzle de exploração por gesto: a pessoa precisa mover o dedo pela tela para revelar uma mensagem escondida.
- Transições leves, feedback visual e suporte a `prefers-reduced-motion`.
- Safe areas do iPhone (`env(safe-area-inset-*)`).
- Sem dependências externas, sem imagens e sem fontes externas: abre direto pelo `index.html`.

## Testar

Abra `index.html` no navegador.

## GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta.
3. Vá em **Settings → Pages**.
4. Escolha a branch principal e a pasta `/root`.
5. Salve e abra o endereço do GitHub Pages.
